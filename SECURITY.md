# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Zooka Royal, please report it by:

1. **Do NOT** open a public GitHub issue
2. Email us at: security@zooka-ai.com
3. Include a detailed description of the vulnerability
4. Wait for acknowledgment within 48 hours

We will work with you to understand and address the issue promptly.

## Disclosure Policy

- We follow a 90-day responsible disclosure timeline
- Security updates will be released as patches to the latest version
- Credit will be given to reporters (unless requested otherwise)
